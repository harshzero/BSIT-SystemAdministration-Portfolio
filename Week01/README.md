## Challenges Encountered

1. **Organizing a portfolio from the beginning.** It is easy to save files wherever convenient, which makes evidence difficult to find later. I addressed this by using a single repository with numbered weekly folders and descriptive filenames.
2. **Learning Markdown structure.** Headings, tables, links, and image paths can break when their syntax or relative path is incorrect. I addressed this by previewing the README in GitHub/VS Code and using relative links.
3. **Building a professional online presence.** A technical profile needs a clear photo, headline, skills, and public information without oversharing. I addressed this by keeping the profile focused on my IT studies and development goals, and by only sharing contact information I am comfortable making public.

## Reflection

Week 1 showed me that system administration is not only about fixing computers or running commands. A professional administrator needs an organized workspace, a dependable record of changes, and a way to communicate technical work clearly. Setting up Git and GitHub gave me a practical method for keeping my files in one place and preserving the history of my work. I can now see why version control is important when configurations, scripts, and documentation change over time.

Creating and improving professional profiles also made me think about how I present my skills. GitHub can demonstrate the actual projects I create, while LinkedIn can help me describe what I am learning and connect with other professionals. These platforms make my progress visible beyond the classroom.

The tools prepared for this course will support the next activities in different ways. Visual Studio Code will help me write Markdown, scripts, and configuration files. VirtualBox and the operating-system ISOs will provide a safe environment for testing Linux and Windows administration tasks without risking my main computer. Git will help me track every improvement. Most importantly, the activity taught me to document work as I do it, not only at the end. That habit will help me become more organized, accountable, and prepared for a future role in system administration.
